## 订阅安装

在 Telegram 中使用运行 TeleBox 的账号发送：

```text
.tpm source add https://github.com/beiwang02/telebox-plugins
```

按需安装，将 `track` 换成其他插件名即可：

```text
.tpm i track
```

安装本仓库全部插件：

```text
.tpm i aix s r save_sticker track yl hb hb hb hb hb hb hb hb hb hb
```

手动更新已安装的远程插件：

```text
.tpm update
```

> 默认命令前缀为 `.`。添加源会替换已有自定义源；安装会替换同名插件。不要用 `i all`，它还会安装官方源插件。`update` 会检查所有已安装的远程插件，不限本仓库。

## 定向抢红包 hb

安装/更新：`.tpm i hb`。`.h hb` 查看完整用法，`.hb <@机器人用户名>` 直接绑定并开启。群聊、私聊、收藏夹均可管理，全局生效。

| 指令 | 作用 |
| --- | --- |
| `.hb <@机器人用户名>` | 添加机器人并立即开启；不删除其它绑定 |
| `.hb list` | 查看编号、开关及最近回调 |
| `.hb on [编号]` | 开启指定绑定 |
| `.hb off [编号]` | 暂停指定绑定，保留配置 |
| `.hb del [编号]` | 删除指定绑定 |
| `.hb status` | 查看状态及最近回调耗时，不是完整历史 |

编号以最新 list 为准；on/off/del 不带编号操作全部。更新保留现有开关，不会擅自恢复已暂停绑定。

平时监听新建和编辑推送。/red 或绑定 Bot 的准备提示可触发备用查询，单窗口最多 2 次，全局间隔至少 2 秒，每分钟最多 6 次。实时推送直接处理，同一红包只提交一次。Telegram 返回限流时按服务端要求暂停。可信准备提示后 15 秒内，支持识别空正文图片上的唯一普通回调按钮。不执行 URL、WebApp、需密码按钮或 inline 代发。

数据在 assets/hb/state.json，单进程使用。领取不发群消息，Bot可能公布名单。最近回调只保存在内存，重载重置；RPC返回不等于到账，也不保证秒抢。
